# ⚡ geng-magnet
A high-traffic optimized Gen.G-focused web platform with Supabase authentication, SendGrid email service, Razorpay payments, and a full Admin Dashboard.

---

## 🚀 Features

### 🔐 Authentication (Supabase)
- Email/password login  
- Token-based secure sessions  
- User table + profile table  
- Ready-to-import SQL file included  

### 💳 Payments
Supports multiple payment providers:
- UPI  
- Razorpay  
- PayPal  
- Visa / Card Payments  

### 📩 Email Notifications (SendGrid)
- Automated order confirmation  
- Forgot password email  
- Admin notifications  

### 🛠 Admin Dashboard
- View all orders  
- Approve/reject users  
- Real-time analytics (via Supabase)  
- Access control (admin-only routes)  

### 🌐 Frontend
- Built with **React + Vite**  
- Fast load time  
- SEO-optimized  
- Responsive UI  

### ☁ API Routes (Serverless)
- `/api/createOrder`
- `/api/sendEmail`
- `/api/admin/orders`
- `/api/admin/users`
